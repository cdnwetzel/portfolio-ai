The chat on this site runs on a home-hosted model. The obvious next question: can that model build things, not just talk? This page is the evidence. Two models were given the identical task through the identical agent harness — a coding-agent session driven over a machine protocol, tools enabled, no human edits — and each build was verified in a real headless browser by synthesizing mouse input and analyzing the rendered pixels.

The task, verbatim

Your task is to create a real-life sand simulator using HTML, CSS, and JS. - There should be a wall around the playground (window). - The playground should be 400x400 pixels and sand particles 4x4 pixels. - The sand particles should roll down like in real life and pile up at the bottom. - Add new sand when the left mouse button is held down.

Read it yourself

Every artifact is committed in the repo — both models' complete source, both harness scripts, and all eight verification screenshots: docs/lab/2026-11-16-local-model-build.

Honest fine print: the managed model was ~3× faster wall-clock, and it implemented the "wall" as in-simulation physics where the local model rendered it visually — both pass every functional check, and the full comparison is in the repo's plan file. The point of this lab isn't "local wins"; it's that the home stack is genuinely capable of agentic coding work, measured rather than asserted.
